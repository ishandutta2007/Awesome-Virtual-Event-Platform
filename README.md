# Awesome-Virtual-Event-Platform

### Top Virtual Event Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**
*Focused on Virtual Conferences, Webinars, Hybrid Events, Networking, Stages, Expo Halls & Attendee Engagement*
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Virtual Event Platforms**. These tools enable organizers to host fully virtual or hybrid conferences, webinars, summits, trade shows, and networking events with registration, multi-stage live streams, breakout rooms, chat, Q&A, polls, virtual booths/expos, networking lounges, analytics, and integrations with CRM/marketing stacks.

**Examples** include Hopin (now RingCentral Events), Airmeet, Goldcast, ON24, BigMarker, Remo, SpotMe, vFairs, Hubilo, InEvent, Bizzabo, Accelevents, Swapcard, and EventMobi (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom stages, live video, ticketing, schedules, and open event data processing — ideal for communities, universities, NGOs, researchers, and developers building transparent, privacy-focused virtual event solutions.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## Open-Source GitHub Projects

- **[eventyay (FOSSASIA)](https://github.com/fossasia/eventyay)**  
  Comprehensive open-source event management platform with ticketing, registration, call for papers, speaker/session management, scheduling, online video, check-in, badges, exhibitions, and plugins. Continuously developed since 2014.

- **[Hi.Events](https://github.com/HiEventsDev/hi.events)**  
  Modern open-source event ticketing and management platform (Laravel + React) for conferences, workshops, festivals, and more — self-hostable with full control over branding, data, and payments.

- **[BigBlueButton](https://github.com/bigbluebutton/bigbluebutton)**  
  Leading open-source web conferencing / virtual classroom system with real-time audio/video, presentation, whiteboard, chat, polls, breakout rooms, recording, and analytics. Widely used as the live-session engine for virtual events.

- **[Jitsi Meet](https://github.com/jitsi/jitsi-meet)**  
  Popular open-source video conferencing platform that can power stages, breakout rooms, and interactive sessions in virtual events. Easy to self-host and embed.

- **[Vercel Virtual Event Starter Kit](https://github.com/vercel/virtual-event-starter-kit)**  
  Open-source Next.js starter used for large conferences (e.g., Next.js Conf). Supports multiple stages, live or pre-recorded streams, sponsor expo, career fair, ticket registration, and customization.

- **[OPENPASS](https://github.com/eventiofoss/OPENPASS)**  
  Free, self-hostable open-source event management platform covering registration, ticketing, check-in, feedback, and event discovery — designed for FOSS and community events.

- **[Buzz](https://github.com/BuildWithHussain/events)**  
  Open-source self-hosted event management platform built on Frappe Framework with tickets, add-ons, sponsorships, check-ins, and attendee self-service.

- **[OpenMeet Platform](https://github.com/OpenMeet-Team/openmeet-platform)**  
  Open-source Meetup.com-style event and community platform for creating groups, events, RSVPs, and real-time chat (AT Protocol native options).

- **[Connect Platform](https://github.com/Inflectra/connect-platform)**  
  Open-source virtual conferencing platform with chat, video, expo/booths, and on-demand content — originally built for InflectraCon and designed for easy self-hosting.

- **[Strive](https://github.com/Anapher/Strive)**  
  Open-source video conferencing platform with breakout rooms, screen sharing, chat, moderated talking, and flexible permissions — suitable as a live-session backend.

- **[MiroTalk SFU](https://github.com/miroslavpejic85/mirotalksfu)**  
  Easy-to-deploy open-source WebRTC SFU video platform with screen sharing, recording, chat, and APIs — useful for custom virtual event rooms.

- **[Apache OpenMeetings](https://openmeetings.apache.org/)**  
  Mature open-source web conferencing and collaboration platform with audio/video, whiteboard, chat, recording, and integration options.

### Additional Strong Open-Source Options

- **Event ticketing & management**: Attendize (classic open-source ticketing), Revel, and various Laravel/Django-based ticket systems.
- **Scheduling & collaboration**: Rallly (open-source meeting/event date polling).
- **Conference websites**: OpenConferenceWare, Symposion (Django conference management).
- **Live interpretation & accessibility**: FOSSASIA eventyay plugins and related interpretation tools.
- **Custom stacks**: Combine **BigBlueButton** or **Jitsi** + **eventyay/Hi.Events** + **Next.js/Vercel starter** + **PeerTube** for streaming + **Matrix** for chat.
- Many community **virtual booth**, **schedule**, **badge**, and **check-in** projects on GitHub.

**Frameworks for building custom systems**: Combine **eventyay** or **Hi.Events** for registration/ticketing, **BigBlueButton** or **Jitsi/LiveKit** for live stages and breakouts, **Next.js** or **Vue** frontends, **PostgreSQL**, **Redis**, **PeerTube** or RTMP streaming, and optional AI tools (Ollama, etc.) for Q&A summarization and content repurposing.
